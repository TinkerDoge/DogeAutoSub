How should the palette toggle look?

Atari Sunset is default. Three ways to switch between the four palettes. Click one.

Click cycles A → B → C → D → A

1 · Cycle button

One click swaps to the next palette. Lives in the title bar where the current theme toggle is. Smallest footprint — but you have to click through to find one you like.

2 · Dropdown menu recommended

Title-bar button opens this menu. See all four at once with names and previews, pick directly. Native macOS feel. Slightly more code but much better UX once there are 4+ themes.

3 · Always-visible swatch row

All four stripes are visible in the title bar at all times. One click = switch. Most discoverable, takes the most title-bar space, can feel busy.
